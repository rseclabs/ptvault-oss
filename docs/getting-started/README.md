# Getting Started with PTVault

This section guides you through installing PTVault, performing first-time setup, and completing your first penetration testing workflow.

- [First-Time Setup](./first-time-setup.md) — Create your admin account and configure the application
- [Quick Start Workflow](./quick-start.md) — End-to-end walkthrough of a typical engagement

## Prerequisites

- Python 3.10 or newer
- A modern web browser (Chrome, Firefox, Edge)
- *(Optional)* Docker for containerized deployment

## Overview

PTVault runs as a local web application on your machine. After starting the server, you access it through your browser at `http://localhost:5001`. All data is stored locally — nothing leaves your machine.

**Typical setup takes under 5 minutes:**

1. Install dependencies
2. Start the server
3. Open your browser and create your admin account
4. Create your first engagement and start collecting evidence
