# Tools

The Tools section provides a suite of built-in utilities for penetration testers. All tools are available without an active engagement.

## In This Section

- [CyberChef](./cyberchef.md) — Data transformation and encoding toolkit
- [MSFVenom Builder](./msfvenom-builder.md) — Metasploit payload command generator
- [Command Hub](./command-hub.md) — Shell one-liners, command reference, Markdown cheatsheet
- [Calculators](./calculators.md) — CVSS 3.1 scorer and Subnet calculator
- [Decoders](./decoders.md) — JWT decoder and PowerShell encoder/decoder
- [Attack Maps](./attack-maps.md) — Visual attack path diagrams

## Quick Reference

| Tool | Use When |
|------|---------|
| CyberChef | Encoding/decoding, hashing, encryption, data analysis |
| MSFVenom Builder | Generating msfvenom payload commands |
| Shells | Finding reverse shell one-liners for a specific language |
| Command Reference | Looking up pentest commands by category |
| CVSS Calculator | Scoring a vulnerability with CVSS 3.1 |
| Subnet Calculator | Calculating network/broadcast addresses from CIDR |
| JWT Decoder | Parsing a JWT token to inspect claims |
| PowerShell Encoder | Creating base64-encoded PowerShell commands |
| Attack Maps | Diagramming the attack path for a report |
